## Stack

- **Java 21**
- **Open Liberty** (latest via `liberty-maven-plugin 3.11.4`)
- **Jakarta EE 11** (`jakartaee-11.0` feature)
- **MicroProfile 7.1** (`microProfile-7.1` feature)
- **Jakarta Data 1.0** (`data-1.0` feature) — leaderboard repository
- **Jakarta Persistence 3.2** — entity mapping, schema auto-creation
- **Jakarta REST 4.0** — REST API at `/api/game/*` and `/api/leaderboard`
- **Jakarta Validation 3.1** — request validation (Bean Validation)
- **PostgreSQL 18** (Docker, pinned image `postgres:18`)

## Schema creation

The schema is created automatically on first startup by Jakarta Persistence's
`jakarta.persistence.schema-generation.database.action=create` property
in `persistence.xml`. Existing tables are left intact on subsequent starts.

No manual migration step is required.

## Supporting services

Start the PostgreSQL database:

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
docker compose up -d
```

Stop and remove:

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
docker compose down
```

To also remove the database volume (clears all leaderboard entries):

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
docker compose down -v
```

## Build

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
mvn package
```

## Run

Ensure the database is running first (`docker compose up -d`), then:

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
mvn liberty:run
```

The game is available at: <http://localhost:9080/jakarta-ee-demo-bob-claude-opus-4-5_3/>

## Test

Unit tests run without any external dependencies:

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
mvn test
```

Integration tests start a Testcontainers PostgreSQL container and the
Liberty server automatically — no manual database setup required:

```
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
mvn verify
```

## Clear the leaderboard

The app has no built-in delete. To reset between runs, connect to the database
and truncate the table:

```bash
# Run from jakarta-ee-demo-bob-claude-opus-4-5_3/
docker compose exec db psql -U guessuser -d guessdb -c "TRUNCATE TABLE leaderboard_entry RESTART IDENTITY;"
```
